This project is a **production-level, real-time digital banking system** built to securely process **millions of transactions** while actively detecting and **preventing fraudulent activity.**

**Key System Features:**
**Robust Architecture**: Designed as a complete microservices-based banking platform.
**Real-time Fraud Detection**: Implements advanced fraud detection patterns and automated triggers to safeguard accounts.
**SAGA Pattern**: Ensures data consistency and transaction integrity across services, preventing partial or stuck transfers.
**Tech Stack**: Developed using **Spring Boot, Apache Kafka** for event-driven communication, **Redis** for caching and **OTP management**, and **MySQL** for persistent data storage.
**Secure Payment Integration**: Includes support for external payment gateways like Razorpay for seamless payment processing.
**API Gateway & Rate Limiting**: Manages secure traffic entry points and protects services from traffic spikes or malicious requests.
**This project provides a comprehensive look at building scalable financial systems, from database design and high-level architecture to real-world integration and testing.**
